# 03. 自動化の設計

**前提**: [02-validation-plan.md](./02-validation-plan.md) の V2/V3 に合格してから着手する。
未合格の段階で作ると、赤字を自動で量産する装置になる。

## 自動化しない部分（人の判断）

> 「候補商品一覧から選ぶのは人の作業」という当初の方針をそのまま採る。

人が判断するのは **候補リストからの最終選択** のみ。その前後は自動化する。

## 設計の核: 候補リストに載せる前にユニットエコノミクスで落とす

01 の結論から直接出る要件。**候補一覧に出す段階で、損益分岐CPAが実測CPAを
超えない商品を機械的に除外する。** これをやらないと、人は「売れそうか」だけで
選んでしまい、C1（構造的赤字）の商品が混ざる。

```
[1] 収集        サプライヤーAPI (AliExpress / CJ) から商品データを取得
                     ↓
[2] 一次フィルタ  売価見込 >= 12,800円 / 原価率 <= 30% / 発送元・配送日数
                     ↓
[3] 経済性ゲート  unit_economics.py で損益分岐CPAを算出
                 損益分岐CPA < 実測CPA x 安全係数 → 除外
                     ↓
[4] スコアリング  需要シグナル(検索ボリューム・競合数・レビュー数)で並べる
                     ↓
━━━━━━━━━━ [5] 人が選ぶ ━━━━━━━━━━  ← ここだけ手動
                     ↓
[6] ページ生成    タイトル・説明文・SEO・画像の生成
                     ↓
[7] 出品          Shopify Admin API: productCreate → productVariantsBulkCreate → 公開
                     ↓
[8] 受注処理      既存ツール (AutoDS / DSers) に任せる
```

## 自作する範囲と既存ツールに任せる範囲

既存ツールが既にカバーしている領域を作り直す価値はない（[sources.md](./sources.md) 参照）。

| 工程 | 担当 | 理由 |
|---|---|---|
| [1] 収集 | 既存 or 自作 | AutoDS/DSers/Spocket がカバー。APIが開いていれば自作も可 |
| [2][3] フィルタ・経済性ゲート | **自作** | 既存ツールにこの機能はない。**ここが差別化点** |
| [4] スコアリング | **自作** | 日本語の需要シグナルは既存ツールが弱い |
| [5] 人が選ぶ | 人 | — |
| [6] ページ生成 | **自作** | 日本語の商品説明・SEO。Spocket のAI生成は英語前提 |
| [7] 出品 | 自作（薄い） | `productCreate` を叩くだけ。作成時は unpublished なので公開処理が別途必要 |
| [8] 受注処理 | **既存ツール** | AutoDS が注文自動処理・追跡番号更新まで持つ。信頼性が要る領域を自作しない |

## 法令要件をコードに織り込む

[sources.md](./sources.md) の法規制から、[6] の生成処理で**必須**になるもの。
後付けにすると全商品の修正が必要になる。

- **配送日数は実日数で出す**（出荷前処理1-7日 + 標準7-16営業日）。
  「即日発送」「在庫あり」を生成テンプレートに入れない（景品表示法）
- **特商法の表記**をストア単位で設置（販売業者名・住所・電話番号・責任者名・
  価格・送料・支払方法・返品ポリシー）
- **商品説明にサプライヤーの誇大表現をそのまま転記しない**。クレームは販売者に向く

## 実装順

1. `tools/unit_economics.py` を関数として呼べる形に整える（済: `per_order()` を import 可）
2. [3] の経済性ゲートを単体で作り、手持ちの候補CSVに対して回す
3. [2] のフィルタを付ける
4. [6][7] を作る（ここで初めて Shopify Admin API のトークンが必要）
5. [1][4] は最後。収集元のAPI仕様に依存するので、[2][3] が固まってから

**2 で止まってもいい。** 候補を手で集めて経済性ゲートに通すだけでも、
C1 の赤字商品を選ばない効果は得られる。
