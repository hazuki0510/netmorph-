# 02. 検証計画

[01-unit-economics.md](./01-unit-economics.md) の結論は**ベンチマーク中央値に基づく机上計算**。
自分の数字で裏を取るまで自動化コードを書く意味がない。ここでは
「何を測れば次に進めるか」を合否条件付きで並べる。

## 検証の順序と合否条件

### V0. 試算の前提を自分の数字に差し替える（コスト: 0円）

| 差し替える値 | 取得元 |
|---|---|
| 為替 | 実勢レート |
| 日本の Shopify Payments 実レート | Shopify 管理画面 / 問い合わせ |
| 仕入値・送料 | AliExpress / CJ Dropshipping の実際の商品ページ |

```bash
python3 tools/unit_economics.py --usd-jpy <実勢> --payment-rate <実レート> \
    --price <候補売価> --cogs <実仕入値> --inbound-shipping-jpy <実送料>
```

**合否**: 売価12,800円以上の候補で損益分岐CPAが 8,529円（導出CPA）を超えるか。
超えなければその商品は候補から外す。

---

### V1. 需要の存在を広告費ゼロで確認する（コスト: 0円 / 期間: 2-3日）

高単価(12,800円以上)かつ海外ドロップシッピングで調達可能なニッチを3-5個挙げ、
各ニッチについて:

- Google トレンド / キーワードの検索ボリュームが存在するか
- 既に日本語で売っている競合がいるか（**いない = 需要がない証拠にもなる**）
- 競合の売価が 12,800円以上か

**合否**: 「検索ボリュームあり + 日本語競合あり + 競合売価が12,800円以上」を
同時に満たすニッチが1つ以上見つかること。0個なら商材モデル自体を再検討
（POD / 国内在庫 / デジタル商品へ）。

---

### V2. 実CPAを小予算で測る（コスト: 3-5万円 / 期間: 1-2週間）

ここが**唯一の本質的な検証**。C1/C3 の分岐は実CPAだけで決まる。

1. Shopify Basic でストアを開設（$29/月・年払い）
2. V1 で通ったニッチの商品を **5-10点だけ手動で出品**（この段階では自動化不要）
3. 特商法の表記（販売業者名・住所・電話番号・責任者名・価格・送料・支払方法・
   返品ポリシー）を設置。**配送日数は実日数（出荷前処理1-7日 + 7-16営業日）で表示**
4. Meta 広告を1商品あたり 5,000-10,000円で配信

**合否**:

| 実測CPA | 判断 |
|---|---|
| 損益分岐CPA 未満 | 合格 → V3 へ |
| 損益分岐CPA の 1-1.5倍 | 保留 → LP改善・クリエイティブ差し替えで再測定 |
| 損益分岐CPA の 1.5倍超 | 不合格 → ニッチ変更、またはモデル変更 |

予算が尽きる前に注文が1件も入らない場合、CVRの上限が測れていないだけなので
予算を増やすか売価を上げる。**「もう少し回せば当たる」で予算を足し続けない**ための
事前の打ち切りライン（例: 累計10万円）を決めておく。

---

### V3. 配送と返品の実績を取る（コスト: V2の売上内 / 期間: 3-4週間）

V2 で入った実注文で測る。ここで初めて 01 の「仮定」が実測になる。

**合否**: 実際の返品・不着・チャージバック率が仮定の 5% 以内に収まるか。
超える場合は 01 の試算をその率で再計算して、まだ黒字か確認する。
配送日数クレームの発生率も記録する（C3 の未検証の成立条件）。

---

### V4. ここまで全部合格して初めて自動化を書く

→ [03-automation-design.md](./03-automation-design.md)

自動化の投資判断は「手作業の時間 × 時給 > 開発工数」で決まる。V2/V3 を
手作業で回した実感がないと、どこがボトルネックか分からないまま作ることになる。

---

## 打ち切り条件

以下のいずれかに当たったら、海外ドロップシッピングから撤退して別モデルを検討する。

- V1 で条件を満たすニッチが0個
- V2 で累計10万円使って実CPAが損益分岐CPAの1.5倍を切らない
- V3 で返品・不着率が試算を黒字に保てない水準

撤退時の代替候補（01 の構造から直接出るもの）:

- **プリントオンデマンド**: 原価率は上がるが国内生産拠点を選べば配送日数問題が消える。
  2028年の輸入課税改正の影響も受けない
- **デジタル商品**: 原価ほぼ0・配送なし・輸入課税の対象外。損益分岐CPAが売価にほぼ等しく
  なるので、C1 の低単価でも成立しうる
- **国内仕入れ・在庫あり**: 配送が速く利益率も高い。ただし仕入資金と在庫リスクが乗る
