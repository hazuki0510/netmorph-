# 01. 収益モデルの試算

結論を先に書く。**計算から直接出るものだけ**を結論とし、根拠のない一般論は
「仮定」として分離している。数値の出典は [sources.md](./sources.md)。
再計算は `python3 tools/unit_economics.py`。

---

## 結論

### C1. 低単価商品は Meta 広告の実勢コストで構造的に赤字になる

売価 4,980円 / 仕入 1,200円 + 送料 300円 のケース:

| 項目 | 金額 |
|---|---|
| 売上 | 4,980 円 |
| 商品原価 + 送料 | -1,500 円 |
| 決済手数料 (2.9% + $0.30) | -189 円 |
| 輸入消費税（現行ルールで免税） | 0 円 |
| 返品・不着の期待損 (5%・仮定) | -324 円 |
| **= 広告前 貢献利益** | **2,967 円**（売上比 59.6%） |

貢献利益がそのまま**広告費に使える上限（損益分岐CPA）= 2,967円 = $19.78**。

これに対し広告の実勢:

| CPAの出し方 | 値 |
|---|---|
| CPC $0.87 ÷ CVR 1.53% から導出 | **$56.86 = 8,529円** |
| 業種別CPA中央値レンジ（報告値） | $26.80-$51.86 = **4,020-7,779円** |

**どの見積りでも損益分岐CPA 2,967円を上回る。** 最も楽観的な $26.80 を採っても
1件あたり -1,053円。損益分岐には広告CVR 4.40%（中央値 1.53% の 2.9倍）が必要。

> 導出CPA $56.86 が報告値レンジ上限 $51.86 を超える点について: 報告されている
> CPA中央値は業種別、CVR/CPC中央値は全業種横断なので、集計母数が違えば乖離しうる。
> 本試算では**レンジ $26.80-$56.86 のどこを採っても結論が変わらない**ので、
> どちらが正しいかは詰めていない。

### C2. 必要売価は「導出CPAで約15,800円以上」「最良CPAで約7,800円以上」

原価率20%固定で、ドロップシッピングの健全ベンチマーク純利益率を満たす売価:

| 目標純利益率 | 導出CPA(8,529円)なら | 最良CPA(4,020円)なら |
|---|---|---|
| 15% | 15,846 円 | 7,807 円 |
| 20% | 17,396 円 | 8,571 円 |
| 25% | 19,283 円 | 9,501 円 |

### C3. 高単価なら成立する

売価 19,800円 / 仕入 4,000円 + 送料 800円:

| 項目 | 値 |
|---|---|
| 広告前 貢献利益 | 13,151 円（売上比 66.4%） |
| 損益分岐CPA | 13,151 円 = $87.67 |
| 導出CPA 8,529円での1件利益 | **+4,621 円** |
| 損益分岐に必要な広告CVR | **0.99%**（中央値 1.53% の 0.6倍） |

月100件で売上 198万円 / 純利益 **約45万円 / 純利益率 23.0%**。
これは健全ベンチマーク 15-25% の範囲内に入る。

**必要CVRが中央値を下回る**ことが重要で、C1 の低単価ケースと逆になっている。
つまり「平均的な広告運用でも成立する」側に入る。

### C4. 損益分岐CPA の感度表

太字が導出CPA 8,529円を超えるセル（＝黒字になりうる領域）。

| 売価 | 原価15% | 原価20% | 原価25% | 原価30% | 原価40% |
|---|---|---|---|---|---|
| 2,980 | 1,915 | 1,759 | 1,602 | 1,446 | 1,133 |
| 4,980 | 3,442 | 3,181 | 2,919 | 2,658 | 2,135 |
| 7,980 | 5,733 | 5,314 | 4,895 | 4,476 | 3,638 |
| 12,800 | **9,413** | 8,741 | 8,069 | 7,397 | 6,053 |
| 19,800 | **14,757** | **13,718** | **12,678** | **11,639** | **9,560** |
| 29,800 | **22,392** | **20,828** | **19,263** | **17,699** | **14,570** |

**売価 12,800円 が概ね下限**。それ以下の価格帯は、原価率をどれだけ絞っても
Meta広告の実勢CPAを賄えない。

## 期限: 2028年4月1日

令和8年度税制改正大綱で、**2028年4月1日以後**の譲渡から:

- 1万円(税抜)以下の越境通信販売も消費税の課税対象になる
- 個人輸入の課税価格 0.6掛け特例が廃止される
- 年50億円超のプラットフォーム事業者へ納税義務を転換（プラットフォーム課税）

現行は「課税価格（海外小売価格×0.6）が1万円以下 → 免税」なので、海外小売価格
約16,666円までが免税だった。この免税が C1/C3 の試算で輸入消費税0円になっている理由。

改正後の影響（売価4,980円ケース、取引額に10%が乗ると仮定した場合）:

| | 貢献利益 |
|---|---|
| 改正前 | 2,967 円 |
| 改正後 | 2,469 円 |
| 差分 | **-498 円 (-16.8%)** |

> **誰が納税義務者になるかは未確認。** 自分が国内のドロップシッピング販売者となる場合の
> 取り扱い、および免税事業者判定との関係は税理士・税関への確認が必要。
> ここでは `--apply-2028-import-tax` で「取引額に10%相当のコストが乗る」最悪ケースの
> 感度を見ているだけ。

**現時点(2026年10月)から約1年半は現行ルールが使える。** この期間に C3 の高単価モデルで
検証を回し切るか、改正後も成立する構造（高単価・国内在庫・POD・デジタル）へ寄せるかを
決める必要がある。

## 試算に入れていないもの

結論を歪める可能性がある未織り込み要素。意図的に省いたものと、データがないものを分ける。

**意図的に省いた（モデルに入れると仮定が増えすぎる）**

- リピート購入 / LTV。1回購入前提で計算している。リピートが乗れば許容CPAは上がる
- オーガニック流入（SEO・SNS）。広告100%前提。これが効けば平均CPAは下がる
- 繁忙期の広告費上昇（CPC +30-35%、CPM +25-66%）

**データがない（要実測）**

- 日本の Shopify Payments 実レート（試算は米国表記の 2.9% + $0.30 を使用）
- 実際の返品・不着・チャージバック率（5%は仮定）
- 為替（150円/USD は仮定。USD建て数値すべてに効く）
- 対象ニッチの実CVR・実CPA（ベンチマーク中央値で代用している）

## 事業リスク（計算ではなく事実として）

- **配送日数**: AliExpress → 日本は追跡付き標準で 7-16営業日、出荷前処理に別途 1-7日。
  高単価商品の購入者がこの日数を許容するかは未検証で、C3 の成立条件に含まれていない
- **景品表示法**: 在庫がないのに「在庫あり」「即日発送」と表示するのは違法。
  無在庫であることと実配送日数の表示設計が必須
- **特定商取引法**: 販売業者名・住所・電話番号・責任者名・価格・送料・支払方法・
  返品ポリシーの明示義務。仕入先への責任転嫁は認められない
- **損害賠償**: 「表示通りの品質でない」というクレームはサプライヤーではなく販売者に向く。
  高単価商品ほどこの金額が大きくなる = C3 のモデルはこのリスクも同時に大きくする
